================================================================================
                           TROUBLESHOOTING
================================================================================

ISSUE: Cannot access admin panel
SOLUTION: Ensure you're logged in as admin user
          Check that your role is set to "admin" in database

ISSUE: "Database connection not available" error
SOLUTION: Check that MySQL service is running
          Verify database credentials in db.php
          Ensure schema.sql has been executed

ISSUE: Cannot create user with "Username already exists"
SOLUTION: Choose a different username
          Usernames must be unique in system

ISSUE: "Password must be at least 6 characters"
SOLUTION: Use a password with 6 or more characters
          Minimum is enforced for security

ISSUE: Cannot delete a user
SOLUTION: If it's your own account, you cannot delete self
          Try deleting a different user account
          If error persists, check MySQL is running
